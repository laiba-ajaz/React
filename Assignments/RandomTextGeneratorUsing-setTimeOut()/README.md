# 🎲 Random Text Generator

A simple React project that displays a random motivational message whenever the user clicks the **Show Random Text** button.

## ✨ Features

* 🎯 Displays a random message on button click
* ⚛️ Uses React `useState` Hook
* ⏱️ Uses `setTimeout()` to hide the message after 3 seconds
* 🎨 Simple and clean UI

## 🛠️ Technologies Used

* React JS
* JavaScript
* CSS
* Vite

## 🚀 How It Works

When the button is clicked, a random message is selected from the messages array and displayed on the screen. After **3 seconds**, the message automatically disappears.

## 📌 Project Purpose

This project was created to practice the **`setTimeout()` function** .
