# React Portfolio

A  personal portfolio website built with **React.js** as part of a React assignment.

## Features

- Functional React components
- Props and reusable components
- Bootstrap  styling
- React Icons
- `useState` and `useEffect`
- Contact form with validation
- React Router
- Dynamic project detail routing

## Pages

- **Home** — Portfolio introduction, skills and featured projects
- **Projects** — Displays all projects
- **Project Detail** — Dynamic project details using `/projectDetail/:id`
- **Contact** — Contact form with validation

## Technologies

- React.js
- JavaScript
- React Router DOM
- React Icons
- Bootstrap 5
- CSS
- Vite
